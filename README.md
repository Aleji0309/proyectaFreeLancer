
# Freelancer Website  

## Description  
This project is a **freelancer portfolio website** created as part of a **Udemy course**. The goal was to build a professional, visually appealing site where freelancers can showcase their skills and services. The website is built with **HTML** and **CSS**.

This project helped me improve my **web design** skills by creating a **responsive** and **interactive portfolio**. I focused on structuring the content properly and making the design visually appealing and easy to navigate using **CSS**.
