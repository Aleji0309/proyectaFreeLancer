- **HTML5** – Semantic structure

- **Netlify** – Deployment

## 📋 Project Description

The Freelancer project is a multi-section website showcasing services, past work, and contact information. It's ideal for freelance professionals or small agencies that want a clean, fast, and accessible site with:

- Service overview  
- Portfolio/projects section  
- Testimonials  
- Contact area (non-functional)  
- Fully responsive layout

No JavaScript was used — all interactions and layout behaviors are handled with pure CSS.

## 📌 Key Features

- Responsive design using Flexbox and media queries  
- Semantic HTML structure for accessibility and SEO  
- Sticky navigation  
- Visual hierarchy using font weights, spacing, and colors  
- Clean, modern UI design

## 🚀 How to Run Locally

1. Clone the repository:

```bash
git clone https://github.com/Aleji0309/proyectaFreeLancer.git
````

2. Navigate to the project folder:

```bash
cd proyectaFreeLancer
```

3. Open `index.html` in your browser.

> No installation or build steps required — this project is 100% static.
